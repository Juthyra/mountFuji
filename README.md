# Mount Fuji — 富士山 · A City Grows

An animated single-file SVG/JS timelapse: you stand in the main street of a settlement and look toward Mount Fuji while it grows from a village into a megacity through the seasons and the day/night cycle.

Open `index.html` in any modern browser.

| Input | Action |
|---|---|
| Hold mouse / `F` / `Shift` | fast-forward |
| `Space` | pause / play |
| `R` | restart |
| `P` | seasonal particles |
| `M` | ambient sound |
| Slider | scrub time of day |
